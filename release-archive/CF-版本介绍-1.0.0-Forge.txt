No Original Trains 1.0.0 — Forge
File: mtr_no_original_trains-forge-1.0.0.jar
Minecraft 1.20.1 · Forge 47.x


ABOUT THIS VERSION

1.0.0 is the first Forge release: the same behaviour as the Fabric build, now on Forge 47.x for Minecraft 1.20.1.

It removes MTR's 378 built-in trains, and only those. Addon packs are never touched. It also fixes addon train gangways.

One thing to note before installing: this build is pinned to MTR 4.0.5 and will refuse to load with 4.0.6+ or 4.1.x. That pin is removed in 1.1.0.


WHAT IT DOES

- Removes MTR's 378 built-in trains from the vehicle list.
- Those trains are never loaded, so their models and textures cost no memory.
- MTR's boats, airships and cable cars are kept. Only trains are removed.
- Fixes addon train gangways — missing, black-and-purple, or oddly long connection pieces between carriages — without modifying your addon zip.
- Addon vehicles are detected at runtime and allowed through automatically. No whitelist editing, ever.
- Trains are chosen from the config file in this version: keepIds and extraRemoveIds. There is no in-game picker yet; that arrives in 1.2.0.


INSTALL

- Drop mtr_no_original_trains-forge-1.0.0.jar into mods/.
- Requires Minecraft Transit Railway 4.0.5 exactly. This build is pinned and will not load on 4.0.6+ or 4.1.x — use 1.1.0 if you are on a newer MTR.
- No other mods required. FerriteCore and ModernFix become hard requirements in 1.1.0.
- Client-side only. The mod aborts with an error if it detects a dedicated server.
- Do not install the Fabric build alongside this one. Both share a mod ID. The file name does not carry the loader yet, so check the jar name carefully.
- Config is generated at config/mtr_no_original_trains.json on first launch: enabled, fixGangway, keepIds, extraRemoveIds.
- Verify it is running: search your log for [MTR_NoOriginalTrains].


KNOWN LIMITATIONS

- Pinned to MTR 4.0.5, as above.
- On a server where other players use MTR's stock trains, you will not see those trains — the filter runs on your client.
- NeoForge is not supported on 1.20.1. MTR has no NeoForge build for Minecraft 1.20.1.
- Known good on Forge 47.4.26.
