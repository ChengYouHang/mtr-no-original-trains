## 三、CurseForge 步骤

1. **主页（Description）**——编辑器右上角切 **Markdown** 模式，贴 `CF-主页介绍.md` 全文，覆盖旧版。
2. 项目 → Upload File，选 `jars/` 里 **Fabric** 那个 jar；Display Name `No Original Trains 1.3.0 (Fabric)`，Release type 选 **Release**，Game Version 勾 `1.20.1`，Loader 勾 `Fabric`；Changelog 框贴 `CF-版本介绍-Fabric.txt`；Relations 确认 MTR / FerriteCore / ModernFix 三个 Required（旧文件填过会继承，检查一遍即可）。
3. 同样步骤传 **Forge** jar，Changelog 框贴 `CF-版本介绍-Forge.txt`。
4. 两份 `CF-版本介绍` 的差别只有：抬头（文件名、加载器）、安装段里的前置后缀。

### Changelog 框没有 Markdown 模式

主页可以切 Markdown，但上传文件时的 **Changelog 框不渲染 Markdown**：`**粗体**` 会原样显示成星号。所以两份版本介绍仍是无 Markdown 的纯文本，直接整段粘贴。

---

## 四、Modrinth 步骤

1. 那个 1.2.0 还在 Under Review，**别动它**，也**不发 1.2.1**（已决定跳过）。
2. 项目 → Create a version：版本号 `1.3.0`，Channel 选 `Release`。
3. 传 Fabric jar：Loaders 勾 `Fabric`，Game versions 勾 `1.20.1`，Changelog 贴 `CHANGELOG-fabric-1.3.0.md`（Modrinth 认 md）。里面已含「Coming from 1.2.0?」一节，把 1.2.1 的追加包过滤功能一起交代了。
4. 同样传 Forge jar，Changelog 贴 `CHANGELOG-forge-1.3.0.md`。
5. Dependencies：MTR、FerriteCore、ModernFix 三个都选 `Required`。
6. 项目正文（Description）分别换成 `Modrinth-Fabric.md` / `Modrinth-Forge.md`。
