这个模组会把 [MTR] 我的世界铁路 自带的内置列车全部移除，你自己装的追加包列车一个都不动。仅客户端。

## 它做什么

MTR 4.0.5 自带 423 个车辆定义，其中 378 个是内置列车。这些车会出现在车辆选择列表里，模型和贴图也会全部加载进内存——就算你一次都不会放。玩主题追加包的话，这 378 个车纯属累赘。装上本模组之后：

- 这 378 个内置列车从车辆选择列表里消失，也不会再生成
- 它们的模型和贴图不再加载，省下一块内存
- MTR 的船、飞艇、缆车全部保留，只处理列车
- 追加包列车默认全部保留。就算某个追加包的车辆和内置列车重名，也不会被误删

## 想留几辆？主菜单里勾

并不是非得 378 个全删。主菜单多了一个「No Original Trains选择面板」按钮，点进去先是一个中转页，三个选项：内置列车、追加包列车、取消。选内置列车：

- 按车系分组，勾一次就是一整个车系，不用一辆一辆找车厢 ID
- 勾选框画的是原版同款斜对勾：实色表示整行全选，半透明表示只选中了一部分
- 支持全选、全不选、恢复默认，列表可以折叠
- 界面显示「已保留 4 / 32 个车系」，随时知道还剩多少
- 保存后弹窗问要不要立即重启，因为改动重启游戏才生效

不想用界面也行，配置文件里的 `keepIds` 照旧有效，两者改的是同一处。

## 追加包列车也能挑

同一个按钮里的「追加包列车」，用来处理另一种情况：某个追加包塞了一两百辆车，把你的车辆列表占满。进去以后是这样：

- **只列真正的列车包。** 判定标准是包里有没有 `mtr:mtr_custom_resources.json` 并且里面声明了车辆。纯材质包、光影包、音效包，不管你装了多少个，都不会出现在这个列表里。
- **新旧两种包格式都认。** MTR 3 时代的 `custom_trains` 写法和 MTR 4 的 `vehicles[]` 写法都会读，没跟着更新的老包也能正常列出列车。
- **三级结构：线路 → 车型 → 单车。** 追加包基本不打车系标签，所以线路和车型都是按包里自己写的名称和 ID 推出来的。上海包 248 辆车进去是 18 条线路，点线路上的 `+` 展开车型，再点车型的 `+` 才是逐辆车。勾线路就整条线一起拦，只想拦某个车型就单独勾它。
- **名字直接读包里的清单。** 所以某辆车被你拦掉以后，下次进来名字还在，不会退化成 `mtr_custom_train_ac01_cab_1` 这种原始 ID。
- **默认一辆都不拦。** 不勾就是全放行。内置列车的保留规则永远优先，两边的设置不会互相打架。

## 搜索：所有选择界面都能搜

1.3.0 起每个选择界面顶部都有搜索框，右侧一个「搜索」按钮。输入后点搜索（或按回车）列表才会过滤，打字过程不会刷新，不会跳来跳去；按 Esc 先清空搜索，再按才退出界面。

- **包列表页搜的是所有包的全部列车。** 在追加包列表页搜索时，搜的不只是包名，而是两个包里所有车一起搜，命中的车型按包分组列出来，包名右边显示命中辆数。点包名进明细页可以继续细调，搜索词会带过去。
- **空格是"并且"。** 搜「上海 16」就是名称或 ID 里两个词都得有。
- **数字不拆开匹配。** 搜 `2` 不会命中 `12号线`，搜 `16` 不会命中 `AC16` 里的数字，线路号不会串到车型号上。在 357 辆真实追加包车的测试集上，这套路由的查准率和查全率都是 100%（旧的朴素包含匹配是 90.9% / 95.7%）。
- **自动剥前缀。** `mtr_custom_train_` 和 `mtr:` 会在匹配前去掉，从日志里复制原始 ID 粘进来也能搜到车。
- **按相关度排序。** 名称全等 → 前缀 → 包含 → 仅 ID 命中，最像的那辆排最前面。

## 冲突提示：勾之前告诉你

- 某辆车同时也在你的内置保留清单里，它的行上会出现「!」标记——保留优先，勾了拦截也不生效，悬停可以看到说明。
- 某个包（或车型）里有车同时被另一个追加包声明，会显示冲突数——这种车一旦拦截，两个包里的它都会消失。

## 追加包怎么保证安全

每次启动，模组会扫描全部资源包里的 MTR 车辆清单：包含全部内置 ID 的那份就是 MTR 本体，其余的都是追加包。被追加包声明过的车辆 ID 默认一律放行，只有你在「追加包列车」页面里手动勾选的才会被移除。万一扫描失败，模组退回内置黑名单，宁可少删也不会动你的追加包。

## 兼容性

内置列车名单不是写死在模组里的，每次启动从你安装的 MTR 本体里现读，所以 MTR 更新之后不用等本模组跟进。支持 MTR 4.0.0 到 4.1.x 的全部版本，包括测试版（只有 4.0.0-beta-8 到 beta-11 不行，缺了内部方法）。Fabric 和 Forge 各一个 jar，行为完全一致，二选一安装，请勿同时安装。

界面文字已完整翻译成 42 种语言，跟随游戏语言显示。

## 前置

- MTR 本体 4.0.0 以上
- FerriteCore（硬前置，缺了不加载）
- ModernFix（硬前置，缺了不加载）

## 配置

首次启动生成 config/mtr_no_original_trains.json：

- enabled —— 总开关
- fixGangway —— 连接件修复开关
- keepIds —— 想保留的内置列车 ID
- extraRemoveIds —— 想额外移除的 ID
- blockedAddonIds —— 想移除的追加包列车 ID（界面里勾选后自动写入）

## 文件

Fabric 版是 mtr_no_original_trains-fabric-1.3.0.jar，Forge 版是 mtr_no_original_trains-forge-1.3.0.jar，文件名带加载器，不会拿错。

## 注意

- 仅客户端，服务端不用装
- 联机时它过滤的是你客户端：服务器里其他玩家放置的内置列车将不会显示，如有顾虑请酌情安装
- 部分追加包车厢连接件会丢失、紫黑或被拉长，本模组顺手修复，不改追加包文件
- 不支持 NeoForge（MTR 在 1.20.1 没有 NeoForge 版）
- 删掉模组即可完全恢复原样，不写存档、不加方块物品
- 想确认生效：日志里搜 [MTR_NoOriginalTrains]
