## 三、CurseForge 步骤

1. 项目 → Upload File。
2. 选 jar（`jars/` 里对应加载器那个）。
3. Display Name / Version 按上表填。**Release type 选 Release**，不要留 Beta。
4. Game Version 勾 `1.20.1`，Loader 勾对应加载器。
5. Changelog 框贴 `CF-CHANGELOG.txt` 全文。
6. Relations 里把 MTR、FerriteCore、ModernFix 都设成 Required Dependency。
7. 提交后，把项目简介（Description）换成 `CF-Fabric.md` / `CF-Forge.md` 全文。

CF 的 Changelog 框不渲染 Markdown，表格会变成一串 `|---|---|`。所以那份是纯文本，用 `===` 分段，别换成 md 版。

---

## 四、Modrinth 步骤

1. 项目 → Create a version。
2. 版本号 `1.2.1`，Channel 选 `Release`。
3. 上传对应 jar，Loaders 勾 Fabric / Forge，Game versions 勾 `1.20.1`。
4. Dependencies：MTR、FerriteCore、ModernFix 三个都加，选 `Required`。
5. Changelog 贴 `CHANGELOG-fabric-1.2.1.md` / `CHANGELOG-forge-1.2.1.md`（Modrinth 认 md，标题和列表都会正常渲染）。
6. 项目正文（Description）换成 `Modrinth-Fabric.md` / `Modrinth-Forge.md`。

Modrinth 现在那个 1.2.0 还在 Under Review，别再动它，直接提交 1.2.1 新版本。
